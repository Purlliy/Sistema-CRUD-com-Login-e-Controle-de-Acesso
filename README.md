# Sistema-CRUD-com-Login-e-Controle-de-Acesso
---
# Proposta da apresentação: 
A apresentação tem o objetivo de explicar sobre um sistema de login e lista de amigos, explicando desde o formulário de login até o cadastro de amigos a lista. Nele é utilizado recursos para organizar o código, como o "require_once", e é utilizado um sistema de sessão que impede de entrar na lista de amigos pelo URL sem que tenha feito um login antes, e caso tente fazer isso, o código irá bloquear o acesso e pedir que faça o login antes. Esse site ele utiliza o sistema CRUD para a criação e a listagem dos amigos.
